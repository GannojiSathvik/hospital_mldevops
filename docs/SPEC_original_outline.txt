Project Title
Healthcare Patient Readmission Risk Prediction  End-to-End DevSecMLOps Project
Main Objective
Develop a machine learning system that predicts whether a hospital patient is likely to be readmitted within 30 days after discharge.
The project must demonstrate the complete lifecycle:
	•	Dataset collection or generation
	•	Data validation
	•	Exploratory data analysis

Important Healthcare Requirements
Use only public, anonymized, or synthetically generated healthcare data.
Do not use real patient names, addresses, phone numbers, email addresses, medical record numbers, or other personally identifiable information.
Include a clear disclaimer that the project is for educational and demonstration purposes only and must not be used for real clinical diagnosis or treatment decisions without professional validation.
Dataset
Create and include a synthetic CSV dataset named:
data/raw/healthcare_readmission.csv
Generate at least 5,000 patient records.
The dataset must include the following input columns:
	•	patient_id
	•	age
	•	gender
	•	bmi

	•	alcohol_consumption

	•	discharge_destination
	•	follow_up_scheduled
	•	insurance_type
	•	admission_type
Target/output column:
	•	readmitted_30_days
Target values:
	•	0 = Not readmitted within 30 days
	•	1 = Readmitted within 30 days
Create realistic relationships between the features and target. For example, patients with more previous admissions, chronic illnesses, emergency visits, abnormal blood glucose, longer hospital stays, and no scheduled follow-up should have a higher probability of readmission.
Include missing values, limited outliers, categorical variables, and class imbalance so that the preprocessing pipeline is realistic.
